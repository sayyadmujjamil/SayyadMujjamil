## 🔄 CI/CD & DevOps

### CI/CD Tools

* **GitHub Actions** — Automated Android build, test, lint and artifact generation
* **Gradle** — Android build automation
* **Git & GitHub** — Version control, feature branches and pull requests

### Typical Android CI/CD Pipeline

```text
Git Push / Pull Request
        ↓
      GitHub
        ↓
  GitHub Actions
        ↓
 Gradle Build
        ↓
Lint + Unit Tests
        ↓
 UI / Instrumentation Tests
        ↓
 Release Build
        ↓
 APK / AAB Artifact
```
